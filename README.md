# Journey to Mars!

This is a little game I made where you are in a rocket ship and are heading to mars 
but what is that? there are meteors incoming! watch out!

This program uses C++ graphics and code to make a small game where you must dodge meteors,  
as they slowly get faster until you finally reach Mars.  
\
Some code in this program, specifically the shapes and shaders, was starter code made by my professor, Lisa Dion, at UVM.  
That being the case this code still shows my knowledge and understanding of C++ in how the code functions and in C++ graphics  
as the majority of the main engine was written by myself.
